Expedia Case Study

Project Overview

Role: UX/UI Designer/Developer

Timeline: Multi-week course project

Platform: Responsive web

Tools: Figma, HTML/CSS/JS, in-class usability testing

This project reimagines Expedia's booking experience with a focus on clarity, consistency, and responsive interactions. The work spans heuristic evaluation, low-fidelity sketches, grayscale wireframes, interactive prototypes, and multiple rounds of user testing.

The Problem

An evaluation of Expedia.com revealed several recurring issues that increased cognitive load for users:

  • Inconsistent pricing language (“$ nightly” vs. “$ per night”)
  • Confusing or unlabeled interactive elements
  • Filters collapsing immediately after selection
  • Overlapping discount programs
  • Trips page mixing searching and managing bookings
  • Ads blending into listings

These issues especially affected first‑time or occasional users who rely on clear labels, predictable patterns, and visible system feedback.

Process

Heuristic Evaluation

We mapped each issue to Nielsen's heuristics and identified opportunities to improve consistency, visibility of system status, and recognition over recall.

Paper Sketches

  • Stronger homepage identity
  • Clearer labels (“Add Trip,” “Helpful Resources”)
  • Standardized pricing
  • Persistent filter feedback
  • Cleaner ad separation
  • Defined page purposes

Grayscale Wireframes

  • Simplified hero search
  • Consistent card layouts
  • Clear hierarchy on checkout
  • Structured Help Center categories
  • Tabs for Upcoming / Past / Create Trip

Usability Testing

  • Users looked for “Help Center,” not “Support”
  • Trips page needed a sign‑in gate
  • Search and checkout flows were described as “easy” and “clean”
  • Some confusion around redundant sign‑in buttons
  • Users wanted more visible recommendations

Final Design Improvements

  • Clarity & Consistency
    • Standardized pricing as $###.## per night
    • Unified iconography for “Stays”
    • Clear labels for all interactive elements
  • Stronger Feedback
    • Persistent active filters with removable tags
    • Inline “Edit” options on checkout
    • Loading spinners for async actions
    • Real‑time search suggestions
  • Improved Navigation
    • “Help Center” renamed and reorganized
    • Trips page now requires sign‑in
    • Ads visually separated from listings
  • Micro‑Interactions
    • Hover effects on cards and buttons
    • Fade‑in transitions on page load
    • Fixed navigation bar

Outcome

The final prototype tested extremely well. Users described the experience as “very easy,” “clean,” and “familiar,” with clear hierarchy and intuitive navigation. The redesign reduces cognitive load, improves system feedback, and creates a more predictable and trustworthy booking flow.

Reflection

This project reinforced the value of evidence-based design. Small details—labels, hierarchy, feedback—had the biggest impact on user understanding. Iterative testing helped refine not just the visuals but the structure and logic of the experience.
